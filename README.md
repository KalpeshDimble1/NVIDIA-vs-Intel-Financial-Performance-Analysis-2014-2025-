# NVIDIA vs Intel — Financial Performance Analysis (2014–2025)

A comprehensive comparative analysis of NVIDIA and Intel's financial performance over a 12-year period, covering the pre-AI and AI boom eras. Built in Excel with dynamic formulas, pivot summaries, and dashboard visualisations.

## Overview

This project analyses quarterly and annual financial data for **NVIDIA** and **Intel**, focusing on net income, gross profit, growth rates, and long-term compounding trends. The data is sourced from [Macrotrends](https://www.macrotrends.net/stocks/charts).

## Key Findings

- **NVIDIA's full-period CAGR (2014–2025):** ~59.5% — net income grew from $585M to $99.2B.
- **Intel's trajectory:** Net income declined from $11.7B (2014) to -$267M (2025), reflecting major strategic and competitive challenges.
- **AI Boom Era (2019–2025):** NVIDIA achieved an ~85.8% CAGR, while Intel's net income turned negative.
- **Crossover point:** Around 2022–2023, NVIDIA's net income surpassed Intel's for the first time and accelerated rapidly.

## Spreadsheet Structure

| Sheet | Description |
|-------|-------------|
| **Income_Profit Analysis** | Quarterly net income and gross profit data for both companies, with annual pivot summaries |
| **Growth Rate Analysis** | Year-over-year growth rates for net income and gross profit, side-by-side comparison |
| **Summary Dashboard** | Annual summary table with growth rates, NI ratios, and cumulative growth index (base = 100) |
| **Relevant Metrics** | CAGR analysis by era, cumulative growth index, and rolling 3-year average net income |
| **Dashboard** | Visual dashboard pulling live data from other sheets — CAGR highlights, key metrics, and charts |

## Data Source

All financial data is sourced from **Macrotrends** ([macrotrends.net/stocks/charts](https://www.macrotrends.net/stocks/charts)), covering quarterly filings for both companies.
